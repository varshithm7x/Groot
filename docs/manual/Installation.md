# Installation

GROOT is a desktop app for macOS, Windows, and Linux. Install it, then choose a folder. No account is required for local writing.


## Why it exists

The desktop app gives Markdown files a fast editor, Forge, canvas, and thinking layer without moving them into a hosted database.

## When to use it

Install GROOT when you want a local workspace for an existing folder or a new personal vault.

## Workflow

Build → launch → [choose a folder](<Open a Vault.md>) → create a note.

## Install

GROOT installers have not been published under this name. Use Node.js 22 or newer, then run `npm ci` and `npm run build` from the repository. Platform packaging commands are `npm run package:mac`, `npm run package:win`, and `npm run package:linux`.

> **GROOT tip**
> Keep the application and your vault separate. Updating GROOT should never replace your notes.

> **GROOT common mistake**
> An installer changes the application, not your vault. Open a vault only after you know which folder you intend to use.
