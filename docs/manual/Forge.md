# Forge

Forge helps you study and organize information from notes in your vault. Open Forge from the dock or with `Ctrl/Cmd+G`.

## Tools

- **Mind Map** builds a visual outline from selected notes. You can create one manually without an AI provider, or generate one with a configured provider.
- **Flashcards** create review cards from a selected note.
- **Quizzes** create questions attached to passages in the source note. Answers are saved with the note's local vault data.
- **Reports** summarize quiz results and point back to the source note.

AI generation requires a configured OpenAI or OpenRouter provider. Review generated material against its source before relying on it. Forge data stays with the vault in the existing `.openonyx` data folder.
