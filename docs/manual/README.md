# Knowledge starts with a folder

GROOT is a local-first knowledge platform. Your vault is a folder. Your notes are Markdown files. The editor, Forge and Vault Intelligence all work from that same source.


## Why it exists

Ideas outlive tools. A folder of readable files lets you change tools without abandoning your work.

## When to use it

Use GROOT when you want one place to write, connect, search, and revisit knowledge without giving up ownership of the files.

## Workflow

1. [Install GROOT](<Installation.md>).
2. [Open a folder as a vault](<Open a Vault.md>).
3. [Write a note](<Writing Notes.md>) and connect it with a descriptive Markdown link.
4. Use [Forge](<Forge.md>) to create study material from a note.
5. Use [Vault Intelligence](<Vault Intelligence.md>) when you want help finding context.

> **GROOT tip**
> Start with a folder you already trust. A small vault with useful notes teaches more than an empty taxonomy.

> **GROOT common mistake**
> Do not treat GROOT as the only copy of your knowledge. Your vault is already portable; back it up like any other important folder.
